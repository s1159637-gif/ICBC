# 湾区智汇 · 大湾区青年跨境金融沉浸式演练沙盒 (ICBC FinTech Demo)

## 项目简介
本原型系统为 2026 年“工行杯”全国大学生金融科技创新大赛参参赛作品。
通过引入 **KYCC（Know Your Customer's Character）** 行为数据诊断引擎，在零资金风险的沙盒环境中捕捉青年用户的决策犹豫与性格特征，最终实现向中国工商银行真实理财产品的合规转化。
